## Read on screen

For local screen reading, download the complete repository using **Code → Download ZIP**, extract it, and open `html/index.html` in your browser. Keep the folders together so the links work. The HTML pages open without a server and use system font fallbacks. GitHub’s repository view shows HTML source; it does not display these pages as a website.

The package includes a GitHub Pages workflow. Once enabled in the repository’s **Settings → Pages** with **Source: GitHub Actions**, its deployment provides the online reading address. Until that deployment succeeds, use the downloaded HTML or read the Markdown directly on GitHub. On a narrow screen, matrix tables scroll horizontally while explanations reflow as ordinary text.

## Print

Choose the PDF matching the paper in your printer, then select **Actual size / 100%**. All three papers use landscape pages. Use the A4 files for DIN A4 paper and the US Letter files for Letter paper.

Every PDF keeps its text at least **40 points (14.1 mm / 0.56 inch)** from the sheet edges. White outer margins avoid printing a full-page background. Fonts are embedded. The layouts have been checked digitally in both sizes; physical printer output has not been tested.

For double-sided matrix sheets, check the printer preview: landscape pages commonly use short-edge turning, but printer terminology varies. Single-sided printing works without that setting.

## Use as project context

The `markdown/` folder contains the three papers and project instructions. The three Markdown papers contain the complete reading text without a YAML header or HTML layout code. They can be read directly on GitHub or supplied as project context. The [project instructions](markdown/project-instructions.md) describe a conversational trial. Its placements remain proposals to inspect, not established verdicts.

The map helps readers distinguish a claim, its supporting basis, and the source's credibility and stated confidence. It provides shared locations and reasons for an assessment, with room for correction as the evidence changes.

The five worked cases are synthetic teaching examples. The map is offered as a practical framework to use and evaluate; its placements do not supply measured truth probabilities or automatic decisions.
