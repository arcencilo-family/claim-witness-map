CWM plugin: support

27 October 2026

Publisher: Frank Gerold Boehm, credited in the CWM papers as Frank Böhm · Arcencilo Family Project · Ibiza.

For bug reports and general help, use GitHub Issues.

Explain what you expected, what happened, and which CWM plugin version and ChatGPT surface you used. If an example is useful, make it short, anonymised or synthetic. Do not post case evidence, private conversations, credentials or personal details: GitHub Issues is public.

If a proposed placement seems wrong, identify the relevant claim, matrix location and reason for your concern using a synthetic example where possible. A different assessment is a reason to inspect the basis, not proof that either answer is correct.

Reports remain as public project history until edited or removed. See the privacy and support notice for data handling and removal options. No particular response time is promised.

The published CWM papers remain available independently of the plugin.
